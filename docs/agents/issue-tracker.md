# Issue tracker

Issues live in GitHub repository `Elmata2/LaVega`. Use `gh issue list` and `gh issue view` for queue and full issue text. Open issues are eligible when selected explicitly or labeled `ready-for-agent` for an unqualified batch. Read `Blocked by:` in the issue body or comments as the blocker convention; if absent, use explicit dependency notes in the issue and linked spec. A closed issue is done.

Post clarifications and completion summaries with `gh issue comment`; then use `gh issue close` after implementation and review. Batch run logs live at `.scratch/implement-batch-run-log.md` and record branch commit plus review outcome.
