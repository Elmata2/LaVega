# LaVega

LaVega — local-first personal finance agent. See `docs/CONTEXT.md`.

Production deployment and the `lavega.dev` Cloudflare connection are documented
in [DEPLOY.md](DEPLOY.md).

## Getting started

```bash
bun install
bun run test
bun run dev
```
