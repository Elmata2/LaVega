## Findings considered and rejected

- **Allocation `unpriced` flag order-dependence** (`packages/core/src/investing/allocation.ts:98-107`):
  rejected on re-read. A bucket that receives any priced position ends with
  `unpriced = false` in both iteration orders, and a bucket with no priced
  position keeps its `null` value. That matches `docs/investing/DASHBOARD.md`
  ("Omit unpriced positions from donut slices and percentage denominator. Show
  their symbols in an adjacent `Waarde onbekend` warning"). Not a bug.
- **Dashboard snapshot in `localStorage`** (`apps/investing-web/src/lib/dashboardResource.ts:256-264`):
  documented in `docs/investing/STACK.md` ("the signed-in user's overview in
  `localStorage`; `signOut()` clears both"). Settled, not a finding. Residual
  risk only if the CSP script allow-list grows.
- **`/api/investing/summary` duplication** (`apps/investing-server/src/app.ts:353-407`):
  `docs/investing/DASHBOARD.md` records it as staying "server-side for one
  release". Deletion is cleanup for a later pass, after that release window.
- **Sector resolution N+1** (`apps/investing-server/src/sectorResolution.ts`):
  real but its cost collapses if the sector read stops building the full
  dashboard for positions (see the rejected/next-item list below); handle after
  the read-model work, not as a standalone micro-fix.
- **`personal.eb_pending_auth` RLS gap** (`db/migrations/0003_eb_flow.sql:25`):
  personal-side table, outside this audit's scope. Track with the personal side.
- **`pi` zod advisory via `ai@7.0.77`** (transitive): supply-chain pass, not
  investing-specific. Bump with the next `ai`/`@ai-sdk` upgrade.
